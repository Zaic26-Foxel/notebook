# Sổ tay ZAIC 2026, bảng DataMate

Sổ tay nội bộ của nhóm <tên đội> thi bảng **DataMate** tại [Zalo AI Challenge 2026](https://challenge.zalo.ai/).

**Xem sổ tay:** https://<tên-tài-khoản-hoặc-org>.github.io/notebook/

## Nội dung

| Trang | Nội dung |
|---|---|
| Tổng quan | Lịch cuộc thi theo giờ thực, các bảng thi, giải thưởng |
| Đề bài | Bối cảnh, nhiệm vụ, đầu vào, đầu ra, ví dụ từng bước, các kiểu đáp án |
| Đánh giá và quy tắc | Cách tính điểm PA, yêu cầu kỹ thuật, hướng dẫn gửi bài |
| Hướng tiếp cận | Luồng xử lý, quy tắc quyết định, lựa chọn mô hình |

Mỗi trang có địa chỉ riêng, ví dụ `.../notebook/#de-bai`.

## Cập nhật

Toàn bộ sổ tay nằm trong một file `index.html`. Muốn sửa thì thay file này (Add file → Upload files), trang sẽ tự cập nhật sau khoảng 1 phút.

## Lưu ý

Nội dung tóm tắt từ trang chính thức của cuộc thi. Khi có khác biệt, [challenge.zalo.ai](https://challenge.zalo.ai/) là chuẩn.
Phân công và tiến độ của nhóm nằm ở Google Sheet riêng, không đưa lên repo công khai này.
